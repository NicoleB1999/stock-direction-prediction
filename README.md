🌐
[לצפייה במערכת ב-Streamlit](https://smart-stock-advisor-final.streamlit.app/)



על הפרויקט

Smart Stock Advisor הוא פרויקט גמר בתחום מערכות מידע ומדעי הנתונים.המערכת משלבת נתוני מניות ונתוני מאקרו־כלכלה לצורך השוואה בין AAPL, GOOGL ו־NVDA, הצגת ביצועים היסטוריים ובחינת תחזיות כיוון יומיות באמצעות מודל Random Forest.

המערכת פותחה ב־Python וב־Streamlit, והנתונים עובדו ונשמרו באמצעות SQL Server.

יכולות המערכת

התאמת מניה לפרופיל משתמש באמצעות שאלון.

השוואת מניות לפי תשואה, תנודתיות ומדדים היסטוריים.

בחירת מניה וטווח תאריכים להצגת גרפים ונתונים.

הצגת תחזית UP או DOWN והסתברות חזויה.

הצגת מדדי ביצוע, מטריצת בלבול וחשיבות מאפיינים.

הזנת נתונים ידנית או העלאת קובץ CSV לקבלת תחזיות.

מקורות הנתונים

Yahoo Finance — מחירי פתיחה, מחיר סגירה מתואם ונפח מסחר.

FRED — ריבית הפד, אינפלציה, אמון צרכנים, S&P 500, VIX ותשואת אג"ח ארה"ב ל־10 שנים.

הנתונים כוללים את השנים 2018–2025.

המודל והתוצאות

המודל הסופי הוא Random Forest Classifier.במהלך ההערכה זוהתה זליגת מידע במשתנים daily_return_high ו־daily_return_low, ולכן הם הוסרו מהמודל הסופי.
